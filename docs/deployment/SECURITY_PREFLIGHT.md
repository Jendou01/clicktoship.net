# Fail-closed deployment preflight

No single check authorizes a host or deployment. Both offline artifact/configuration checks and actual running application/host checks must pass; an unavailable tool/check is BLOCKED, not green. Never print secret env files, rendered Compose secrets, full container env, SQL payloads or raw exceptions.

1. Verify reviewed Git SHA, clean tree, protected hosted CI success and independent approval. Resolve three release image digests; verify archive hashes against a protected trusted manifest and publisher/provenance policy. A local image ID does not pass the remote release digest check.
2. `python3 scripts/deployment/preflight.py --secrets /protected/path --host staging.example.test --image registry.example.test/api@sha256:<reviewed> --image registry.example.test/web@sha256:<reviewed> --image registry.example.test/gateway@sha256:<reviewed>` checks only booleans/codes (run as the authorized host operator able to read protected files; never relax world permissions): exact host/origin, pinned refs, protected non-symlink files, private directory, separate strong secret presence, encrypted secure sessions, exact proxy and local-only mail. Placeholder hashes are not accepted evidence. Local `--local-image-ids` is exclusively rehearsal scope. Real SMTP requires separately reviewed private transport configuration; this simulation validator does not certify it.
3. Run `php artisan security:check-config` in the actual runtime container. Must pass exact IP-only trusted proxies, host allowlist, HTTPS, no debug, encrypted Redis sessions, host-only Secure/HttpOnly/SameSite cookies, exact stateful origin, private mail transport, approved sanitized diagnostic store, valid APP_KEY, restricted actual DB login and unchanged closed financial/export/scanner gates. It intentionally rejects normal development.
4. Independently verify runtime role cannot CREATE/ALTER/TRUNCATE or directly write money; owner/migrator credentials unavailable to API/workers; function/schema ownership and public grants reviewed. Privileged administrative SQL is not a tenant-scoping mechanism. No RLS certification.
5. Verify `nginx -t`, actual cert chain/hostname/expiry, unauthorized401, authenticated ready200, English/Arabic pages, unknown host rejection, spoofed forwarding ignored and sensitive paths404. TLS1.2/1.3, no tickets, headers, upload limits; full nonce-based CSP and TLS cipher/OCSP policy require actual ingress review. The inactive http-redirect.conf.example provides exact-host308 on internal8080; no HTTP listener is enabled by Compose. Port80 stays closed until its exact-host/certificate/redirect-only mapping is separately reviewed and authorized.
6. No published internal service or debug dashboard, no secrets in images/Git/args/logs, host firewall/least privilege/patching, volumes and secret ownership, resource caps, no default passwords, revocation, recent MFA and grants. Test Docker published ports from outside the approved firewall after authorization; local checks do not prove it.
7. Verify encrypted off-host backup + key escrow + object consistency + restore signoff, storage/scanner/residency/retention, queue split/timeout/retry/recovery, singleton scheduler, private monitoring and on-call. Missing evidence blocks remote staging. No software toggle can waive these approvals.
